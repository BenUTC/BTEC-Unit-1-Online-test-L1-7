Before you start

  • There are questions worth 50 marks in total. Some questions are worth more than one mark.
  • You have to finish. The timer is at the top of the screen.
  • Answer one question per page. Use Next and Back to move.
  • You can flag a question and come back to it before you submit.
  • When you finish you will get your score and a results file to download. Send that file to your teacher.

The questions appear in a different order for each student.
