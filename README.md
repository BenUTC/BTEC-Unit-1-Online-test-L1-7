# Unit 1 Online Test (BTEC First ICT, The Online World)

A self-marking onscreen practice test for Lessons 1 to 7. It runs as a web page, so it works on any
school computer or tablet with a browser. No logins, no server, no cost.

## How it works for students

1. The student opens the test link, types their name and class, and clicks **Start**.
2. Questions appear one per page, in a random order for each student, with a 60 minute timer.
3. When they finish they get their score and click **Download my results file**.
4. They send you that one file (Teams, email, or a shared folder). That is how the mark is recorded.

The test marks itself. Every question is multiple choice, choose-two, or matching, so there is no
written answer to mark.

## How you get the results as a spreadsheet

1. Collect the `results_*.json` files the students send you into one folder.
2. Open `marks.html` (just double-click it, or host it next to the test).
3. Drag all the student files onto the page. You see a table with each student, their score, a
   breakdown by topic, and the time they took.
4. Click **Download all as spreadsheet (CSV)** to open it in Excel.

Nothing leaves your computer. The collator reads the files in the browser only.
